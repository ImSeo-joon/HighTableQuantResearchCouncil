# Font assets

The Chinese web fonts in this folder are character subsets generated from Noto Sans SC and Noto Serif SC.

- `high-table-sans-sc.woff2`: Noto Sans SC variable-font subset
- `high-table-serif-sc.woff2`: Noto Serif SC variable-font subset

Noto fonts are distributed under the SIL Open Font License. See `LICENSE-NOTO.txt` for the license text.

Chinese display headings use a local Kai-style font stack (`STKaiti`, `KaiTi`, `Kaiti SC`, `FZKai-Z03`) with the bundled Noto Serif SC subset as fallback. No proprietary display font file is redistributed.

If substantial Chinese content is added, regenerate the subsets so every new character remains available.
